# 口袋记账

离线可用的个人记账本，数据只保存在你自己的设备里，不上传、不联网。

网址：https://procyonaphina.github.io/ledger/

## 安装方法（装一次，以后离线也能用）

**iPhone**
1. 用 Safari 打开网址（微信/QQ 内置浏览器不行，点右上角选「在 Safari 中打开」）
2. 点底部「分享」→「添加到主屏幕」→「添加」

**安卓**
1. 用 Chrome 或 Edge 打开网址
2. 点右上角「⋮」→「安装应用」或「添加到主屏幕」
3. 用国产浏览器的话，在浏览器菜单里找「添加到桌面」，各家叫法略有不同

**电脑**
用 Chrome 或 Edge 打开网址，点地址栏右边的「安装」图标即可，也可以直接在浏览器里用。

## 使用须知
- 之后请只从桌面/主屏幕图标打开记账。图标版和浏览器网页版的数据是分开的
- 数据只存在这台设备上。清除浏览器数据、换手机、手机损坏都会丢失
- 请定期在「更多 → 导出备份」保存备份文件，换设备时用「导入备份」恢复
- 如果网址打不开，换个网络（Wi‑Fi / 流量）再试。装好之后离线也能用
